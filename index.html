START IN A MINUTE

Simple from the first click.

Start using Notebook immediately. You can keep everything local or set up the optional online transfer vault when you want to move a snapshot to another device.

STEP 01

Open your workspace

Create pages, organize ideas, build collections, and track tasks. Changes save to your current browser automatically.

STEP 02

Create a private code

In Settings, use a strong passkey and upload an encrypted snapshot to your own configured Cloudflare KV vault.

STEP 03

Restore anywhere

Open the same deployed site on another laptop, enter the code and passkey, and restore the workspace. Delete the code when you're done.
